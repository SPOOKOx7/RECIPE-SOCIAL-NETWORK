# 🍽️ Recipe Social Network

A modern and responsive **Recipe Social Network** web application where users can share recipes, discover trending dishes, like posts, and interact with other food enthusiasts. This project was developed as part of the **CODTECH IT SOLUTIONS Internship Program**.

---

## 📌 Project Overview

The Recipe Social Network provides a user-friendly interface that allows users to:

- Share their favorite recipes
- Browse recipes posted by others
- Like and comment on recipe posts
- Search for recipes
- View trending recipes
- Explore top chefs
- Experience a responsive and attractive UI

---

## 🚀 Features

- 🏠 Home Feed
- 👨‍🍳 User Profiles
- 🍽️ Recipe Posting
- ❤️ Like Functionality
- 💬 Comment Feature
- 🔍 Recipe Search
- 📈 Trending Recipes
- 🌟 Top Chefs Section
- 📱 Responsive Design

---
